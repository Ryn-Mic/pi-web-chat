# Agent Note: 移动端提问导航重构为悬浮胶囊（Floating Prompt Navigator）

Status: implemented

## Problem

原先的用户消息历史跳转（MessageAnchors）存在三大移动端人机交互缺陷：

1. **入口侵占输入区空间**：嵌套在 Composer 底部操作栏内，在手机窄屏上与图片附件、模型切换、思考强度、上下文圆环和发送按钮严重争夺水平空间，容易引起按钮折行或软键盘弹起时的误触；
2. **全屏遮挡与操作断层**：点击后直接弹出一个占据半个屏幕的 Bottom Sheet 遮罩，不仅打断当前会话上下文阅读，而且需要经过“打开 -> 翻找 -> 点击 -> 遮罩淡出”的冗长操作闭环；
3. **缺乏上一问/下一问单手步进**：用户在手机翻阅长会话时，最核心诉求往往是“快速回看一下上一条提问”或“跳到下一问”，原先必须每次打开弹窗重复选择。

## Decision

1. **Composer 底部完全解放**：
   - 从 `Composer.tsx` 底部控制栏中彻底移出 MessageAnchors，腾出输入区右侧空间，保证模型与发送按钮在移动端舒适的点按热区。
2. **重构为右下角悬浮提问胶囊（PromptNavigator）**：
   - 将导航组件直接挂载在 `MessageList` 消息流视口内（`absolute right-3.5 bottom-4 z-20`），居于向下滚动按钮右侧，互不干扰；
   - 胶囊采用垂直微药丸结构（宽约 32px，高约 80px，支持毛玻璃与深色微光边框）：
     - 顶端提供「上一问」快速按钮（`↑`），点击平滑滚至上一条用户消息并触发高亮；若该消息未加载，自动无缝触发历史分页拉取；
     - 中间实时展示当前视口距离最近的提问序号与总数（如 `3/8`），随滚动动态更新；点击可展开包含全部提问的侧向气泡面板；
     - 底部提供「下一问」快速按钮（`↓`），点击直达下一条提问；
   - 当会话只有 1 条或 0 条提问时组件自动隐匿；在任意侧边栏打开时自动避让。
3. **完善四国语言本地化**：
   - 补齐 `previousQuestion`（上一问）、`nextQuestion`（下一问）、`questionsList`（提问大纲）在英、中、日、韩四种语言下的翻译。

## Alternatives considered

- **顶栏标题下拉大纲菜单** — 否决：在手机单手操作场景下，顶栏距离拇指操作热区过远，不如右下角悬浮胶囊便于盲操与单手步进。
- **将提问大纲收纳进左侧抽屉（SessionsDrawer）** — 否决：每次切换提问都需要从屏幕左缘滑出抽屉，无法实现连续顺畅的“跳上一问 -> 扫一眼回复 -> 再跳上一问”。

## Consequences

- **收益**：输入框底栏彻底摆脱拥挤；在长会话中用户只需单手拇指轻点即可在前后多次提问之间自由穿梭；无需任何全屏遮罩打断，阅读体验如翻书般流畅；
- **后续维护**：提问可见性计算依赖 `data-msg-index` 属性，后续修改消息外框节点时需保留该 DOM 属性。
