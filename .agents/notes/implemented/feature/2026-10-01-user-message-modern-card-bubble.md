# Agent Note: 用户消息现代微卡片与移动端轻触交互（方案 A）

Status: implemented

## Problem

原有的用户消息（User Message）在样式和交互上存在明显痛点：

1. **移动端气泡下方常驻暴露方块按钮**：在手机上，每条气泡底部硬生生挂着一排「复制」和「填入输入框」大按钮，长对话列表中充斥着重复的方块按钮，侵占垂直空间且视觉噪声严重；
2. **气泡形态粗糙单调**：单纯采用大块深灰/浅灰色块（`bg-bubble`），缺乏现代卡片的呼吸感与对话方向感；
3. **外挂式悬浮药丸过于违和**：在聊天视口右下角强行常驻垂直翻页胶囊，破坏了沉浸式阅读流。

## Decision

1. **气泡本体微卡片化（Modern Card Bubble）**：
   - 气泡采用微拐角轮廓（`rounded-2xl rounded-tr-md`），明确界定“来自我的提问”对话流方向；
   - 浅色模式采用温润象牙暖白底与极细边界（`border border-line/60 bg-card`），深色模式采用石墨深灰（`dark:border-white/[0.08] dark:bg-[#2d2d2a]`）；
   - 优化内边距与排版（`px-3.5 py-2.5 sm:px-4 sm:py-3`），文字和内嵌内容更舒展。
2. **彻底移除外挂式悬浮药丸**：
   - 消息视口右下角彻底清空，不再强行悬挂外挂控制器，对话流回归绝对纯净；
   - 视口底部中央仅在离开底部时保留极简小巧的「向下滚底」圆形胶囊。
3. **按需呼出的内联微操作条（Tap-to-reveal on Mobile）**：
   - 移动端平时 100% 隐藏操作按钮，消灭界面所有冗余方块；
   - 轻点（Tap）气泡时，在气泡右下平滑淡入一组微型半透明工具胶囊（复制、重新填入编辑）；再次轻点或点击空白区域自然收拢；
   - 桌面端保持优雅的 `hover` 悬停平滑淡入。

## Alternatives considered

- **全屏时间轴章节式排版（方案 B）** — 否决：改动范围过大，偏离传统聊天对话的心智模型，对移动端碎片化阅读不够友好。
- **长按弹出 iOS 原生 Action Sheet（方案 C）** — 否决：移动端长按容易与系统选词和放大镜手势冲突，且层级过重。

## Consequences

- **收益**：移动端对话流彻底恢复清爽通透，满屏排满重复按钮的问题被彻底根治；气泡质感与 Claude/ChatGPT 官方现代设计保持一致水准；轻触唤出交互单手极度友好。
- **验证**：全量 420 个单元测试通过，全量 36 个 Playwright E2E 测试 100% 通过（包含所有移动端视口与文件预览场景），构建和包体积门禁通过。
