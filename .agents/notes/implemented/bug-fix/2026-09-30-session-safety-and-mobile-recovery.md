# Agent Note: 会话授权与移动端恢复边界

Status: implemented

## Problem

认证、WebSocket 输入、历史窗口与移动端导航存在缺少组合验证的边界。登录凭据单独获取第二因素材料、授权撤销未覆盖既有连接、异常命令错误路径再次抛出，会影响服务安全和所有会话可用性。Codex 尾窗滑动、跨标签分页和预览重渲染会使历史加载入口、滚动位置和浏览器返回栈失配。

## Decision

认证接口不返回令牌、TOTP 密钥或二维码，首次绑定通过服务器本机的受限配置文件完成；凭据只保存在受限文件，不输出到日志。授权撤销和超时必须同时约束 HTTP 与既有 WebSocket。协议入口校验真实输入，拒绝提示词时安全关联 requestId；客户端在清空草稿前检查同一字符、附件和 UTF-8 帧预算，避免失败后发送状态或重连循环。

历史窗口变化建立显式重置语义；客户端同步历史边界并使过期分页响应失效。移动预览导航层绑定挂载生命周期，分页滚动补偿绑定原容器与原标签。会话索引按文件合并刷新并分块扫描；Git 文件路径明确区分仓库根与会话目录。

restart 在停止 daemon 前校验目标，失败保留现有服务。聊天静态依赖必须完整进入 PWA 缓存闭包，重预览模块维持懒加载。开发等待端口与代理配置共用事实源；CI 运行真实浏览器回归并复用一次构建的产物。

## Alternatives considered

- 只补防御性 try/catch：无法修复授权撤销、输入契约和历史边界，拒绝。
- 直接替换整个传输协议或引入 AG-UI：当前问题发生在本项目拥有的会话恢复、认证和分页层；增加协议迁移不能消除这些缺陷，拒绝。
- 一次重写大文件、增加新前端栈或依赖：改动面会盖过可复现缺陷，本次沿用现有模块并仅提取有明确所有权的逻辑。
- 截断所有工具输出：改变用户能看到的信息。字节预算和按需全文通道需要独立契约，本次优先保证历史连续与渲染身份；保留完整结果。

## Consequences

- 已审查的认证、异常命令、窗口滑动、返回栈、跨标签滚动、并发索引、Git 子目录和 restart 缺陷有针对性回归。
- 类型、测试、构建、Note、打包与真实浏览器流程通过；调试监听和状态隔离，3141 健康。
- 版本分支从最新 origin/main 建立，快进保留已审查的前置提交；本次 v0.1.121 修改相对 1c8538b 可独立审查，main 不被本地合并或直接推送。

## Risks

首次 2FA 绑定入口改变，需要在 README 和登录页说明本机配置路径。窗口重置会释放已加载历史，需要能重新加载且不混入过期响应。缓存闭包变更需要同时验证首屏、文件预览和断网应用壳。

## Implementation and validation

- 凭据目录为 0700、文件为 0600；显式启动 token 先覆盖持久文件，后续登录继续重读文件以支持轮换。HTTP setup 不提供第二因素材料。退出、超时、绑定和命令执行均检查连接授权。
- 命令校验与 UTF-8 编码预算由 shared/client-command.ts 共用。客户端先校验再进入发送状态，重连重放已验证的原始帧；服务端拒绝关联安全提取的请求 ID。
- Pi JSONL entry 与 Codex native item 为 UI 消息提供稳定 ID。Codex 水合代次约束分页，滑动窗口显式重置客户端历史，过期响应不安装。
- 每文件共享扫描任务，扫描缓冲为 256 KiB；Git 使用异步子进程、literal pathspec 和 cwd 相对路径，部分暂存状态不重复转换同一文件路径。
- PWA 缓存按 emitted dependency graph 决定，包含聊天共享依赖并排除预览独占 chunk、worker 与 CSS。聊天静态闭包约 1.30 MiB，precache 约 3.31 MiB；门禁分别为 2 MiB 和 6 MiB。
- 本机 Node 24.16.0 下 npm test 361/361、typecheck、notes:check、build、pack:check、npm pack --dry-run --ignore-scripts 与 diff 检查通过。包为 6.79 MiB packed / 20.65 MiB unpacked / 226 files。
- 首轮 CI 暴露两个 daemon 预检测试对工作区 dist 的依赖。改为临时安装夹具并加入无构建时保持 daemon 状态的回归；完整测试在无 dist 的临时干净检出副本中再次 361/361 通过，生产 build 前置检查与 CI 顺序保留。
- Playwright Chromium 13/13，通过真实 HTTP 与隔离文件/Git/PWA，并用确定性 Agent 帧覆盖移动宽度下的返回、父重渲染、失败重试、跨 tab 滚动、窗口滑动、断线恢复及授权导致的卸载。未验证真实 iPhone/WebKit/Android 设备。
- 本次未安装依赖、更新全局安装、重启生产、合并 main 或发布。只读检查 127.0.0.1:3141 健康、运行 v0.1.120；该运行版本与本次 v0.1.121 构建区分。

单条巨型输出仍保留完整内容；缓冲分块不限制单个 JSONL 行和单条消息的体积。字节级历史预算、全文按需通道及真实移动设备性能验收继续作为独立契约工作。
